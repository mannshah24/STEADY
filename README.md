## 🔧 Technical Architecture

### How Protection Works (Simple Version)

1. **Peak Tracking**: STEADY remembers your portfolio's highest value
2. **Drawdown Calculation**: Continuously measures distance from peak
3. **Threshold Detection**: Alerts when you cross your Life Mode threshold
4. **Automatic Response**: Rebalances to safer allocation
5. **Recovery Mode**: Gradually returns to growth as markets stabilize

### Smart Contract (Solana)

- Written in Rust using Anchor framework
- Deployed on Solana for speed and low fees
- Uses Program Derived Addresses (PDAs) for account management
- Integrates Pyth Oracle Network for real-time price feeds

### Frontend (Next.js)

- React-based interface with smooth animations
- Real-time WebSocket connections for live updates
- Wallet Adapter for secure, non-custodial connections
- Responsive design for mobile and desktop

### Non-Custodial Design

- Your wallet signs all transactions
- Smart contract has zero withdrawal permissions
- Open-source code for complete transparency
- No backend servers storing your data

## 🛠️ Setup Instructions

### Prerequisites

- Node.js 18+ and npm/yarn
- Rust 1.75+
- Solana CLI 1.18+
- Anchor CLI 0.30.1
- Phantom Wallet browser extension

### Installation

1. **Install frontend dependencies:**

   ```bash
   npm install
   ```

2. **Install Anchor CLI (if not installed):**

   ```bash
   cargo install --git https://github.com/coral-xyz/anchor --tag v0.30.1 anchor-cli
   ```

3. **Set Solana to devnet:**

   ```bash
   solana config set --url devnet
   ```

4. **Generate a new keypair (if needed):**

   ```bash
   solana-keygen new
   ```

5. **Airdrop devnet SOL:**
   ```bash
   solana airdrop 2
   ```

## 🚀 Running the Project

### Start Frontend

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build Anchor Program

```bash
anchor build
```

### Deploy to Devnet

```bash
anchor deploy
```

**Important:** After deployment, update the program ID in:

- `Anchor.toml` (replace the placeholder ID)
- `lib/constants.ts` (update `STEADY_PROGRAM_ID`)
- `programs/steady/src/lib.rs` (update `declare_id!`)

### Run Tests

```bash
anchor test
```

## � Frequently Asked Questions

### Is STEADY actually non-custodial?

Yes. Mathematically and cryptographically impossible for STEADY to access your funds. The smart contract has zero withdrawal permissions. You sign every transaction. Your keys, your crypto, always.

### How is this different from a trading bot?

Trading bots try to make you money by predicting markets. STEADY protects you from loss by responding to actual risk. We don't trade for profit. We rebalance for safety.

### What if I want to exit?

Anytime. No lockups, no penalties, no questions. Change your Life Mode, withdraw, or completely disconnect. You're always in control.

### Does STEADY guarantee I won't lose money?

No. Crypto is inherently risky. STEADY reduces downside by acting faster than humans can, but it can't eliminate risk entirely. Think of it as a seatbelt, not a guarantee you won't crash.

### How much does it cost?

Currently deployed on Solana devnet (free testnet). Production version will have minimal transaction fees (paid to Solana network, not to STEADY).

### What about upside? Will STEADY limit my gains?

Protection triggers on the downside. If markets go up, STEADY tracks your new peak and adjusts. The goal is to let you capture upside while limiting downside.

### Can I use STEADY while traveling?

That's exactly what Focus Mode is for. Set it before you board the plane. STEADY watches while you're offline.

### Does the AI make decisions without me?

The AI explains and suggests. You define the rules (Life Mode, thresholds). STEADY enforces them. You can override anytime.
